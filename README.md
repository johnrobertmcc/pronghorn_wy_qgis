# Pronghorn Migration Corridor Analysis
## Wyoming/Colorado — Path of the Pronghorn

Visualization of GPS telemetry data for Pronghorn (*Antilocapra americana*) 
using QGIS. Data sourced from the Beck & Hennig study via MoveBank.

The Path of the Pronghorn in Wyoming is the longest land migration in the 
continental United States — a 150-mile corridor used for thousands of years.

## Key Observations
- Dense core seasonal range visible in southwest Wyoming
- Individual migration tracks radiating north and south from core range
- I-80 highway corridor visible as a significant movement barrier — 
  an active wildlife management challenge in the region

## Tools & Methods
- QGIS 3.x
- MoveBank telemetry data (Beck & Hennig, University of Wyoming)
- Points converted to individual path vectors, grouped by animal ID
- Styled by individual for corridor density visualization
- CRS: EPSG:4326
